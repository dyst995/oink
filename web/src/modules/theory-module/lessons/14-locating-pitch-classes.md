# Locating pitch classes on the neck

**Prerequisites:** Twelve pitch classes; half steps; tuning; fretboard memorization drill  
**Next:** Octave relationships on the neck

## Concept

Each pitch class appears in **more than one place** on frets 0–12. Those places are the same class at different string/fret addresses — octaves or unisons of that class, not different “notes” in the pitch-class sense.

Strategy: start from an open-string anchor (or any fretted note you already know), count half steps along a string, then hunt the same class on neighboring strings. The Unit A flashcard drill trains recall; this lesson trains **deliberate search** — given a name, find several addresses on purpose.

Duplicates are useful: the same class under your fingers in different octaves lets you move a melody or chord tone without changing its name.

## Examples

- Pitch class `C` between frets 0–12 includes (among others): B string fret 1, A string fret 3, G string fret 5, low E / high e fret 8, D string fret 10.
- Finding `F♯` on the D string: open `D` + 4 frets → fret 4.

## Exercises

1. Pick `A`. Find every occurrence on frets 0–12. Count them; there should be several.
2. Pick a random pitch class and a random string. Land that class on that string between frets 0–11 (fret 12 repeats the open class).
3. Call a class, find it on the lowest string you can, then the highest string you can, within frets 0–12.

**Done when:** given a pitch class, you can point to at least three locations on the neck without only using one memorized “box.”
