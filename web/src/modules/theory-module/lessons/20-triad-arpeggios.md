# Triad arpeggios

**Prerequisites:** Triads on string sets  
**Next:** Diatonic triads

## Concept

A **triad arpeggio** plays the chord tones **one after another** (R–3–5 or any order/inversion) instead of sounding them all at once. It is the same pitch classes as the triad, unfolded in time.

## Underlying logic

If you can spell a triad and find its tones on a string set, an arpeggio is that spelling performed melodically. Inversions of the arpeggio simply start on 3 or 5. Across the neck, the same three pitch classes repeat in new octaves and string sets.

## Musical significance

Arpeggios outline harmony so a single-note line can state the chord without strumming. They are the bridge from “I know the chord tones” to “I can improvise through changes.”

## Guitar application

`C` major on strings 4–3–2:

- Block chord root position `10 9 8` (`C E G`)
- Arpeggio: play those frets in sequence ascending and descending, naming R/3/5
- First-inversion arpeggio from `E G C` (`14 12 13` or `2 0 1`)
- Second-inversion from `G C E` (`5 5 5`)

Then connect: ascend `C E G` in one area, continue to the next higher `C` you know, still only chord tones.

Ear: arpeggiate major then minor (`C E♭ G`) and hear the third change.

## Exercises

1. Spell and arpeggiate `G` major and `G` minor ascending/descending on strings 4–3–2 in root position; name each tone.
2. Play `C` major arpeggios in all three inversions on 4–3–2; say which chord tone you start on.
3. Over a metronome in eighths, arpeggiate `| C | Am | F | G |` one bar each using nearby string-set tones (chord tones only).
4. Find `D` major arpeggio tones on strings 3–2–1 and 5–4–3; play one octave on each set.
5. Improvise 4 bars on a static `Em` using only `E G B`, then allow one approach note that resolves to a chord tone.

## Mastery criteria

- **Fretboard:** Play triad arpeggios in all inversions on at least one string set.
- **Practical:** Outline a short progression with triad arpeggios in time.
- **Aural:** Distinguish major vs minor quality from an arpeggiated triad you play.
- **Application:** Use arpeggios as melody skeletons, not only as exercises.
