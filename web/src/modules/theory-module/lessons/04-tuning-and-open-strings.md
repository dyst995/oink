# Tuning and open strings

**Prerequisites:** Half steps and whole steps

**Next:** Locating pitch classes on the fretboard

## Concept

**Tuning** is the set of pitches your open strings produce. In **standard tuning**, from string 6 (lowest, thickest) to string 1 (highest, thinnest):

| String | Open note | Pitch (octave) |
| --- | --- | --- |
| 6 | `E` | `E2` |
| 5 | `A` | `A2` |
| 4 | `D` | `D3` |
| 3 | `G` | `G3` |
| 2 | `B` | `B3` |
| 1 | `E` | `E4` |

These open strings are your **anchors**: six notes you can name with no counting. Every other fretted note is found by counting half steps (frets) from one of them.

The gaps between neighboring open strings follow a pattern:

| Strings | Distance in half steps | Interval |
| --- | --- | --- |
| 6 to 5 | 5 | perfect 4th |
| 5 to 4 | 5 | perfect 4th |
| 4 to 3 | 5 | perfect 4th |
| 3 to 2 | 4 | major 3rd |
| 2 to 1 | 5 | perfect 4th |

## Underlying logic

Standard tuning is a **convention**, not a law. It is built mostly of fourths so that common chords and scales fit under the hand, with one major third between strings 3 and 2 that keeps the highest strings within easy reach of the lower ones. Other tunings (drop D, open G, DADGAD) rearrange these gaps, and every shape you know shifts accordingly.

The intervals between open strings tell you how to relate any two strings:

- Moving to the next **higher** string (a lower string number, such as 6 to 5) at the **same fret** raises the pitch by 5 half steps, except between strings 3 and 2, where it raises it by 4.
- Equivalently, a note on string 6 matches the note on string 5 **five frets lower** (string 6 fret 5 = string 5 open), except across the G-to-B gap, where it is four frets lower.

Check that string 6 and string 1 are two octaves apart: `5 + 5 + 5 + 4 + 5 = 24` half steps, which is 2 x 12. That total is a quick check that you remember the gaps correctly.

Do not rely on a mnemonic alone ("Eddie Ate Dynamite...") for more than recalling the six names. It gives you the open strings but says nothing about the 5-5-5-4-5 spacing, which is what you will use when you navigate between strings.

## Musical significance

Tuning defines which pitch classes are available as open strings, which in turn shapes what is easy to play. In keys such as `E`, `A`, `D`, and `G`, open strings double as roots, fifths, and other chord tones, so open-position chords ring fully. This is one reason certain keys feel idiomatic on guitar.

Tuning also fixes the **reference pitch**: `A4` = 440 Hz is standard. If your guitar is slightly flat or sharp as a whole it still plays "in tune with itself," but not with a piano or recording. For this reason you tune strings to an external reference or tuner, and then check them against each other.

## Guitar application

Use the five-string relationships to tune by ear and to verify each string:

1. String 6 fret 5 should match open string 5 (`A`).
2. String 5 fret 5 should match open string 4 (`D`).
3. String 4 fret 5 should match open string 3 (`G`).
4. String 3 **fret 4** should match open string 2 (`B`).
5. String 2 fret 5 should match open string 1 (`E`).

When two strings are close but not equal, you hear a slow wobble called **beating**. The slower the beats, the closer the match. A tuner gets you near; your ear confirms the relationship between strings.

Approximate frequencies of the open strings: `E2` 82.4 Hz, `A2` 110 Hz, `D3` 146.8 Hz, `G3` 196 Hz, `B3` 246.9 Hz, `E4` 329.6 Hz.

Ear: play open string 5, then open string 4 and sing the lower note, then the upper. The distance you hear is a perfect fourth. Play open strings 3 and 2 afterwards; the gap is slightly narrower, a major third. That narrower sound is the audible trace of the 4-half-step gap.

## Exercises

1. Without looking, name the six open strings from string 6 to string 1. **Check:** `E A D G B E`.
2. Which fret on string 3 matches open string 2? Which fret on string 5 matches open string 4? **Check:** string 3 fret 4, and string 5 fret 5.
3. Play string 6 fret 5 and open string 5 together. Detune string 5 slightly flat and listen for beating, then restore until the beating stops. **Check:** the beats slow and vanish as the pitches match.
4. Find an `A` on string 6, string 4, and string 3, using only frets 0-7. **Check:** string 6 fret 5, string 4 fret 7, string 3 fret 2. (Open string 5 is also an `A`, so the open `A` makes a fourth answer.)
5. Add up the five gaps between open strings and confirm the total is two octaves. **Check:** 5 + 5 + 5 + 4 + 5 = 24.

## Mastery criteria

- **Conceptual:** You can explain that standard tuning is a convention and describe its 5-5-5-4-5 half-step spacing.
- **Written:** You can write the open string names and octave numbers for all six strings.
- **Fretboard:** You can state the fret that matches an adjacent open string for every string pair, including the string 3 to 2 exception.
- **Aural:** You can tell by ear when two strings match and hear beating when they do not.
- **Practical:** You can tune all six strings using a tuner and then verify them against each other with the 5th-fret (and 4th-fret) method.
- **Application:** You can name which open strings are the root, fifth, or fourth of a given key, for example in the key of `A`, open `A` is the root, open `D` is the fourth, and open `E` is the fifth.
