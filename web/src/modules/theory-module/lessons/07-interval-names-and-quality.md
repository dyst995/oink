# Interval names and quality

**Prerequisites:** Half steps and whole steps; scale degrees and formulas  
**Next:** Intervals in music

## Concept

An **interval** is the distance between two pitch classes (or two pitches). Every scale step and every chord tone is an interval from somewhere — usually from a root or tonic.

Intervals have two parts:

1. **Number (size)** — count letter names inclusively from the lower note to the upper. `C` to `E` is a **3rd** (C–D–E). `C` to `G` is a **5th**. `C` to `C` an octave up is an **octave** (8th). Unison is a **1st**.
2. **Quality** — how wide that numbered size is in half steps, compared with the major scale from the lower note.

From a major scale built on the lower note, the unaltered degrees give the **diatonic** qualities:

| Degree above 1 | Interval name |
| --- | --- |
| 1 | Perfect unison |
| 2 | Major 2nd |
| 3 | Major 3rd |
| 4 | Perfect 4th |
| 5 | Perfect 5th |
| 6 | Major 6th |
| 7 | Major 7th |
| 8 | Perfect octave |

**Perfect** applies to 1, 4, 5, and 8. **Major** applies to 2, 3, 6, and 7 when they match the major scale.

Alter that distance by a half step and the quality changes:

- Major → shrink one half step → **minor** (m2, m3, m6, m7).
- Perfect → shrink one half step → **diminished**; stretch one half step → **augmented**.
- Major → stretch one half step → **augmented**; minor → shrink one more → **diminished**.

Spelling still uses letters. `C` to `E♭` is a **minor 3rd** (letters C–D–E). `C` to `D♯` is an **augmented 2nd** (letters C–D) — same piano key as `E♭` often, different interval name because the letter span differs. That distinction matters when you stack chords and write keys.

Half-step counts (handy check after you name by letters):

| Interval | Half steps |
| --- | --- |
| m2 | 1 |
| M2 | 2 |
| m3 | 3 |
| M3 | 4 |
| P4 | 5 |
| A4 / d5 (tritone) | 6 |
| P5 | 7 |
| m6 | 8 |
| M6 | 9 |
| m7 | 10 |
| M7 | 11 |
| P8 | 12 |

## Examples

- `G` to `B`: letters G–A–B → 3rd; in G major, `B` is degree 3 → **major 3rd** (4 half steps).
- `G` to `B♭`: still a 3rd by letters; one half step smaller than major → **minor 3rd**.
- `F` to `C`: letters F–G–A–B–C → 5th; matches F major → **perfect 5th**.
- `C` to `F♯`: letters C–D–E–F → 4th; one half step larger than perfect → **augmented 4th**.

## Exercises

1. From `D`, name the interval up to each of: `E`, `F`, `F♯`, `A`, `C`, `C♯`. Use letter count first, then quality.
2. Spell a major 3rd and a minor 3rd above `B♭`. Confirm different letters than if you had used the enharmonic shortcut wrongly.
3. On one string, play a root, then +2 frets (M2), +4 frets (M3), +7 frets (P5). Name each interval as you play.

**Done when:** you can name an interval by letter size plus quality, and you can give its half-step width without treating enharmonic pitch classes as automatically the same interval name.
