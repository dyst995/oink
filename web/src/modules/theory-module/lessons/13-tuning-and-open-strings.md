# Tuning and the open strings

**Prerequisites:** The twelve pitch classes  
**Next:** Locating pitch classes on the neck

## Concept

**Standard tuning** fixes six open-string pitch classes, low to high:

`E – A – D – G – B – e`

(The high string is written `e` only to tell it apart from the low `E`; both are pitch class E, different octaves.)

Every fretted note on a string is counted in half steps from that string’s open pitch class. Fret 0 = open. Fret 1 = one half step up. Fret 12 = an octave up (same class again).

The open strings are anchors, not a second theory. The pitch language from Units A–D does not change on the guitar; the neck is a grid of that language.

Adjacent open strings are mostly perfect fourths apart (`E`→`A`, `A`→`D`, `D`→`G`, `B`→`e`). The break is `G`→`B`: a major third. That irregularity is why some cross-string shapes shift when they cross the B string.

## Examples

- Low E string fret 3: open `E` + 3 half steps → `G`.
- A string fret 2: open `A` + 2 → `B`.
- Open high `e` and open low `E`: same pitch class, two octaves apart in standard range terms (different pitches).

## Exercises

1. Say the open strings low→high and high→low until automatic.
2. Without the guitar, name the pitch class at frets 0, 1, 2, 3 on the D string.
3. Tune (or check) the guitar to standard. Play each open string and name it out loud.

**Done when:** you can list EADGBe both ways and treat any fret as “open class + N half steps.”
