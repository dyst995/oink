# Three notes per string

**Prerequisites:** Major scale on the neck; CAGED  
**Next:** Natural minor; relative and parallel keys

## Concept

**Three notes per string (3NPS)** is a way to organize a seven-note scale across the neck so that each string carries exactly three consecutive scale notes. With six strings that gives 18 notes, which cover about two and a half octaves of the scale. Starting on a different scale degree on the lowest string gives seven different patterns (positions), and each overlaps the next.

3NPS is an organizational tool, not a theory. It does not say which notes to play. It gives a consistent grid of the scale that you can pick evenly and slide between.

## Underlying logic

### How the grid is built

Take the scale notes in order and deal them onto the strings from string 6 upward, three per string: notes 1, 2, 3 on string 6; notes 4, 5, 6 on string 5; and so on. On each string, play the three notes in order as consecutive scale degrees. Start the pattern from a different degree and you get a different position.

On guitar the strings are mostly a fourth apart (five frets), with the `G` to `B` pair a major third apart (four frets). That changes the fret shape for the third and second strings, but the scale-degree logic stays the same.

### Two positions in `C` major

**Position starting on `G`** (frets 3 to 8). Each row is one string, in scale order.

| String | Notes | Frets |
| --- | --- | --- |
| 6 | G A B | 3 5 7 |
| 5 | C D E | 3 5 7 |
| 4 | F G A | 3 5 7 |
| 3 | B C D | 4 5 7 |
| 2 | E F G | 5 6 8 |
| 1 | A B C | 5 7 8 |

**Position starting on `A`** (frets 5 to 10).

| String | Notes | Frets |
| --- | --- | --- |
| 6 | A B C | 5 7 8 |
| 5 | D E F | 5 7 8 |
| 4 | G A B | 5 7 9 |
| 3 | C D E | 5 7 9 |
| 2 | F G A | 6 8 10 |
| 1 | B C D | 7 8 10 |

Moving from the `G` position to the `A` position, each string drops its first note and adds the next scale note, so **the two positions share two notes per string.** On string 6, `A B` (frets 5 and 7) belong to both. That overlap is how you connect positions.

### The seven starting degrees

Starting on each of the seven degrees (`C`, `D`, `E`, `F`, `G`, `A`, `B`) on string 6 gives a different shape. Here each shape is named by its starting note; there is no single standard numbering. The shapes are not interchangeable, because the `G` to `B` string pair changes the fret spacing.

### Why organize by three

- Even picking: three notes per string suits alternate picking and legato (hammer-ons and pull-offs).
- Your hand stays in one place: each position spans about five to six frets.
- Overlaps give you connections: the shared two notes per string let you slide into the next position.

### What 3NPS does not do

- It does not show chords or the key. You must still know where the root and the chord tones are.
- It is not the only way to move across the neck. Pentatonic boxes and CAGED shapes handle the same notes differently.
- It applies only to seven-note scales. A five-note pentatonic scale does not divide into threes, so pentatonic patterns use two notes per string. Other seven-note scales (natural minor, harmonic minor) have their own 3NPS grids built the same way, with their own fret patterns.

## Musical significance

3NPS gives even runs and makes scale practice systematic. It is most useful when combined with knowledge of the notes and the harmony. The grid is only the scale. Whether a run sounds like `C` major or `A` minor depends on where you start, where you land, and which notes you stress against the chord, not on the grid itself. Lessons 35 and 36 add the chord-tone targets that give the harmony.

## Guitar application

### Practice sequence

1. Learn the `G` position and the `A` position above, one string at a time.
2. Play ascending and descending with alternate picking (down-up), so the picking pattern is the same on every string.
3. Name each note while playing, or at least name the root `C` whenever you pass it (string 5 fret 3, string 3 fret 5, string 1 fret 8 in the `G` position).
4. Connect: play the `G` position up to the highest string, then slide into the `A` position using shared notes (on string 1 the `G` position has `A B C` and the `A` position has `B C D`, so `B` and `C` are shared).

### Linking to CAGED

The `G` position here lies around frets 3 to 8, which includes the `A`-shape `C` (`x35553`) and the `G`-shape `C` (`875558`). Check that the chord tones `C E G` lie inside the grid: string 5 fret 3 (`C`), string 5 fret 7 (`E`), string 4 fret 5 (`G`).

## Exercises

1. Play the `G` position and the `A` position above, ascending and descending, saying the note names.
2. Build the position starting on `C` (string 6 fret 8) yourself, then check. Answer: string 6 `C D E` at 8 10 12; string 5 `F G A` at 8 10 12; string 4 `B C D` at 9 10 12; string 3 `E F G` at 9 10 12; string 2 `A B C` at 10 12 13; string 1 `D E F` at 10 12 13.
3. Build the position starting on `G` in `G` major (the scale has `F♯`). Answer: string 6 `G A B` at 3 5 7; string 5 `C D E` at 3 5 7; string 4 `F♯ G A` at 4 5 7; string 3 `B C D` at 4 5 7; string 2 `E F♯ G` at 5 7 8; string 1 `A B C` at 5 7 8. Compare with the `C` major `G` position above and name what changed (`F` becomes `F♯` on strings 4 and 2, which moves those notes up one fret; everything else is identical).
4. Play the `A` position slowly and name every `C` you pass. Answer: string 6 fret 8, string 3 fret 5, string 1 fret 8.
5. Pick three consecutive positions and play from the low string up to the high string, then slide to the next position using the shared notes.

## Mastery criteria

- **Conceptual:** define 3NPS and say what it organizes and what it leaves out.
- **Written:** write the three notes on each string for a given 3NPS position.
- **Fretboard:** play two adjacent 3NPS positions in `C` major and name the shared notes.
- **Fretboard:** connect two positions with a slide without losing the beat.
- **Aural:** hear the scale notes in order and identify the starting degree by ear.
- **Application:** use two 3NPS positions to play a short phrase that lands on a root or chord tone.
