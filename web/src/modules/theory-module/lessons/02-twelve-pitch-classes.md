# The twelve pitch classes

**Prerequisites:** Pitch, octave, and pitch class  
**Next:** Half steps and whole steps

## Concept

Western fretted music (and equal-tempered keyboards) work with a closed set of **twelve pitch classes**. After the twelfth step you land on the same class again, one octave higher.

Only seven letters are used for naming: `C D E F G A B`. That is not enough for twelve classes. The other five classes are named with **accidentals**:

- **Sharp (`♯` or `#`)** raises a letter by one step of the twelve.
- **Flat (`♭` or `b`)** lowers a letter by one step of the twelve.

So the twelve classes, written with sharp names going up from `C`, are:

`C`, `C♯`, `D`, `D♯`, `E`, `F`, `F♯`, `G`, `G♯`, `A`, `A♯`, `B`

(and then `C` again).

Some classes have two common spellings. `C♯` and `D♭` name the **same** pitch class. That shared identity is an **enharmonic** equivalent: one sound-class, two spellings.

Why two spellings exist: later, scales and keys need one letter per degree. `G` major wants `F♯`, not `G♭`, so each degree keeps a distinct letter. The spelling is a bookkeeping choice for harmony, not a second pitch class.

This lesson is the naming system. Finding those names on the neck comes after half steps and the fretboard drill.

## Examples

- Seven naturals: `C D E F G A B`. Five remaining classes need accidentals.
- Same class, two spellings: `F♯` / `G♭`, `A♯` / `B♭`, `C♯` / `D♭`, `D♯` / `E♭`, `G♯` / `A♭`.
- `E♯` is enharmonic with `F`. `C♭` is enharmonic with `B`. Those spellings show up in some keys; they are not new classes beyond the twelve.

## Exercises

1. Write the twelve pitch classes starting from `C`, using sharps for the in-between names. Then write the same circle starting from `C` using flats for those five.
2. For each pair, say out loud: “same pitch class”: `C♯`/`D♭`, `D♯`/`E♭`, `F♯`/`G♭`, `G♯`/`A♭`, `A♯`/`B♭`.
3. Answer in one sentence: why do we bother with two spellings if the class is the same?

**Done when:** you can list the twelve classes without looking, and you can explain enharmonic spelling as “same class, different name for later scale logic,” not as twelve-plus-extra notes.
