# Pitch, octave, and pitch class

**Prerequisites:** none  
**Next:** The twelve pitch classes

## Concept

Music uses **pitch**: how high or low a sound is.

Some pitches feel like “the same note,” just higher or lower. Sing any note, then the next matching “same note” above it. That distance is an **octave**. The higher one vibrates twice as fast as the lower one. Your ear hears kinship; physics supplies the ratio.

A **pitch class** is the name shared by all pitches an octave apart. The pitch class `A` includes every `A` in every octave. The low open A string and a high `A` are different pitches, one pitch class.

Why this matters: scales, chords, and keys are built from pitch classes. Octaves place those classes higher or lower on the instrument. Confusing the two makes the fretboard look like dozens of unrelated frets instead of a small set of names repeating.

Guitar detail for later use, not a new theory: each fret is a fixed step in pitch. The same pitch class will appear again twelve frets higher on the same string — that is an octave, not a different letter.

## Examples

- Piano: middle `C` and the `C` above it are an octave. Same pitch class: `C`.
- Guitar: open low `E` and the 12th fret on that string are an octave. Same pitch class: `E`.
- “Play in A” usually means use pitch classes from a collection centered on `A`, across whatever octaves the part needs.

## Exercises

1. Pick any fretted note. Play it, then find the pitch one octave higher on the **same** string (12 frets up, if it fits). Say out loud: “same pitch class, higher pitch.”
2. Play open A, then find another `A` somewhere else on the neck (any octave). Confirm by ear: does it lock as “the same note family”?
3. Write three pairs from instruments or songs you know that share a pitch class but not a pitch (example: low E string open vs high E string open — same class `E`, different octaves).

**Done when:** you can explain pitch vs pitch class in one sentence each, and you can point to one octave pair on the guitar without guessing.
