# Octave relationships on the neck

**Prerequisites:** Pitch, octave, and pitch class; locating pitch classes  
**Next:** Intervals on the neck

## Concept

An **octave** is the same pitch class twelve half steps away. On one string that is simply **twelve frets up**.

Guitarists also use short **cross-string octave shapes** — finger geometries that land the same class on another string. Those shapes are **navigation tools**, not definitions of what an octave is. The definition stays: same pitch class, twelve half steps (or a multiple).

Useful geometries in standard tuning (same class, not always the same sounding octave register depending on direction):

- Same string: +12 frets.
- Skip one string, +2 frets — common when the pair does not cross the G→B break awkwardly (e.g. low E→D, A→G).
- Skip one string, +3 frets — often when crossing toward or over the B string (e.g. D→B, G→e).

Learn them as “where else is this class,” then verify by ear. If a shape and the ear disagree, trust the ear and recount.

## Examples

- Low E fret 3 (`G`) → D string fret 5 (`G`): skip one string, +2 frets.
- A string fret 3 (`C`) → G string fret 5 (`C`): same geometry.
- D string fret 5 (`G`) → B string fret 8 (`G`): skip one string, +3 frets (crosses toward B).

## Exercises

1. Pick any fretted note. Find the same class twelve frets higher on the same string (if it fits).
2. From low E fret 5 (`A`), find the matching class on the D string using a cross-string octave. Check by ear.
3. Explain in one sentence the difference between “octave as a musical interval” and “octave shape as a fingering shortcut.”

**Done when:** you can move a known pitch class to another octave location on purpose, and you do not treat a fingering shape as a theory axiom.
