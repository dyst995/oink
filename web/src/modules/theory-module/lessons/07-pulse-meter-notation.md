# Pulse, meter, and rhythmic notation

**Prerequisites:** Basic counting  
**Next:** Subdivisions, syncopation, and feel

## Concept

**Pulse** (beat) is the steady tap under the music. **Tempo** is how fast that pulse moves (often marked in BPM).

**Meter** groups beats into bars (measures). A **time signature** like `4/4` means four quarter-note beats per bar; `3/4` means three. The top number is how many beats; the bottom number names which duration gets one beat (`4` = quarter note).

Common written durations (relative lengths):

| Symbol idea | Name | In `4/4`, relative to a quarter |
| --- | --- | --- |
| whole | whole note / rest | 4 beats |
| half | half note / rest | 2 beats |
| quarter | quarter note / rest | 1 beat |
| eighth | eighth note / rest | 1/2 beat |
| sixteenth | sixteenth note / rest | 1/4 beat |

A **dot** after a note adds half of that note’s value (dotted quarter = 1.5 quarters). A **tie** joins two notes of the same pitch into one sustained duration.

This is **notation literacy**, not advanced sight-reading: enough to read examples and write simple rhythms.

## Underlying logic

Rhythm is independent of pitch. The same chord progression can use different meters and note values. Counting (`1 2 3 4`) anchors duration to the pulse so “an eighth note” means something concrete.

Guitar tab alone often hides duration; knowing note values lets you communicate and practice rhythm precisely.

## Musical significance

Without a stable pulse and meter, harmony and melody lose their place in time. Groove, hooks, and phrasing all depend on how events sit against the beat.

## Guitar application

Set a metronome to 80 BPM in `4/4`. Mute strings and play:

- Quarters on each beat for 4 bars
- Half notes (hit on 1 and 3) for 4 bars
- Whole notes (hit on 1 only) for 4 bars

Then clap or pick a written pattern such as: quarter, two eighths, quarter, quarter — counting `1 2 & 3 4`.

Relate to a simple staff line mentally: notes sit on a pulse grid even when you only see tab later.

## Exercises

1. At one tempo, play 4 bars each of whole, half, quarter, and eighth notes on an open string. Count aloud.
2. Write (or tap) a 2-bar `4/4` rhythm using a dotted quarter plus an eighth, then two quarters. Play it locked to a click.
3. Explain the difference between a tie (same pitch, one sound) and a slur (connect different pitches — articulation, not duration math).
4. Change the metronome to `3/4`. Play quarters for 8 bars without inserting a fourth beat.

## Mastery criteria

- **Conceptual:** Define pulse, tempo, meter, and time signature.
- **Written:** Read and write basic durations, dots, and ties in `4/4`.
- **Practical:** Perform whole/half/quarter/eighth values against a metronome.
- **Aural:** Keep a steady pulse while durations change.
