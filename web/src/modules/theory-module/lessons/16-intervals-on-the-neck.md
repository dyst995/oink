# Intervals on the neck

**Prerequisites:** Interval names and quality; locating pitch classes  
**Next:** Scales across the neck

## Concept

Every named interval is a **half-step count** plus a **letter spelling**. On the guitar that count appears in two main ways:

- **Horizontal:** along one string (N frets = N half steps).
- **Across strings:** root on one string, the other note on a higher or lower string — several fingerings for the same interval.

Prefer knowing “M3 = 4 half steps, letters a third apart” before collecting a catalog of shapes. Shapes are memory aids; the interval name is what transfers to chords and arpeggios.

Watch the G→B major-third tuning break: a fingering that works on E–A–D–G often shifts one fret when the upper note lands on B or e.

## Examples

- M2 on one string: root, two frets higher.
- P5 across strings: a common shape is root on A string, fifth on D string two frets higher (e.g. A fret 3 `C`, D fret 5 `G`… wait that's C to G = P5. Root on A fret 0 `A`, D fret 2 `E` = P5).
- m3: three frets on one string, or other cross-string grips — verify with half steps.

## Exercises

1. From a root on the A string, play m3, M3, P4, P5 on the **same** string. Name each.
2. Play the same four intervals with the upper note on a **different** string. Adjust if you cross onto the B string.
3. Spell and play a major 3rd and a minor 3rd above `B♭` in two fingerings each.

**Done when:** you can produce a named interval from a chosen root in at least two fingerings and still name it correctly after moving.
